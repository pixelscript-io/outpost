Know before you join.

Features

Everything a DayZ launcher should do

Find a server fast

  • Search by server name, IP address or map
  • Filter by map, first or third person, full servers, BattlEye and vanilla (no mods)
  • Sort by name or players
  • Favorites, saved on your computer
  • Shows the servers that have players right now, kept from last time so it starts instantly and refreshed in the background
  • Select a server and Outpost asks it directly for its mods, password and ping

A ready-to-join checklist

  • Game version against the server's version, with who needs to act if they differ
  • Mods installed, missing or out of date, read straight from the game server. Any mod it gives no Workshop ID for is named, not guessed
  • Download size and a time estimate from your own last download
  • Free disk space before and after the download
  • Open slots, how many players are queuing on a full server, and whether a password is needed
  • One main button that changes with the situation

Mods, handled for you

  • Downloads and updates mods through the Steam client you already use
  • Live progress for every mod
  • Download and play in one click
  • Links each mod and copies its BattlEye keys, so servers accept it
  • Outpost never sees your Steam password

Take control of your mods

  • Every installed mod with its size and when you last used it
  • Clean up mods you have not used for a while, with a preview of the space you get back
  • Verify files and repair damaged mods in one click
  • Mod sets: save a group of mods, launch it without a server, share it as a short code

Launch your way

  • Profile name, which some servers require
  • Launch parameters laid out like the official launcher: window mode, world, profiles folder, CPU cores, memory and more
  • A live preview of the exact command line
  • Server passwords, never saved to disk
  • Set the game folder yourself if it is somewhere unusual

Stays out of your way

  • Crash report with the exit code explained and a Copy diagnostics button
  • Get a desktop notification when a server you are waiting on updates to your game version (while Outpost is open)
  • Updates itself, with a signed update you approve first
  • A tiny installer that needs no administrator rights
  • No account, no ads and no tracking

Questions

Good to know

Is it free?

Yes. There is no account, no ad and no paid tier.

Does it need my Steam login?

No. Steam does the downloading, signed in as you. Outpost only asks the Steam client to subscribe to a mod and watches its progress, so it never sees your password.

Why does Windows warn me about the installer?

The installer is not code-signed yet, so Windows SmartScreen may say the publisher is unknown. Choose More info, then Run anyway. Updates inside the app are separately signed and checked before they install.

Is Outpost official?

No. It is an independent tool and is not affiliated with or endorsed by Bohemia Interactive.

What does it collect?

Nothing about you. There is no account and no analytics, and your settings and favorites stay on your computer. To work, Outpost talks to its own server list service, the game servers you select, Steam and GitHub (for updates). Like any website or game server, those can see your IP address.

Requirements

  • Windows 10 or 11, 64-bit
  • Steam, running and signed in
  • DayZ, installed through Steam
  • About 3 MB to install, plus space for your mods
