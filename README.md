# Outpost

A personal DayZ server browser and launcher for Windows.

- Browse and filter servers, with a "ready to join?" checklist for each one
- Download missing mods through Steam, with sizes and progress
- Launch DayZ with the right mods, keys and parameters
- Manage installed mods: clean up, verify, repair, and save mod sets

## Download

Get the latest installer from the [Releases](https://github.com/pixelscript-io/outpost/releases) page. It installs for the current user and does not need administrator rights. Once installed, Outpost checks this page for updates and asks before installing one.

Requires Windows, Steam and DayZ.

## Unofficial

Outpost is an unofficial tool. It is not affiliated with or endorsed by Bohemia Interactive. DayZ is a trademark of its owner.

This repository hosts the releases, the source of the landing page (in `site/`) and the server list service the app downloads its list from (in `api/`). The app itself is not published here.
